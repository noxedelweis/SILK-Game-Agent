# SILK Game Agent

Experimental local-first agent for The Elder Scrolls III: Morrowind with OpenMW telemetry, an offline Morrowind knowledge base, and Ollama-backed planning.

## Releases

Prebuilt versioned ZIP packages are published under [Releases](https://github.com/noxedelweis/SILK-Game-Agent/releases). The standalone updater can check public stable releases, verify the GitHub asset SHA-256 digest, run tests, and preserve the existing SQLite knowledge base.

This repository is for the **SILK Game Agent** experiment, not the main SILK Desktop app. The game, personal data, local wiki SQLite databases, credentials, and OpenMW installations are not distributed here.

## Status

Experimental prototype. The agent does **not** yet autonomously play through Morrowind. The OpenMW bridge currently provides read-only telemetry and the knowledge Q/A component is being improved.
